BrickView – Real Estate Analytics Platform :

A Real Estate Analytics Web Application built using Streamlit, Pandas, and SQLite3.
This project enables users to explore property listings, analyze trends, visualize data on maps, and perform complete CRUD operations.

 Filters screen :

 Multi-select **City filter**
 **Property Type** dropdown (Apartment, Villa, Condo, etc.)
 **Price range slider**
 **Agent filter**
 **Date range picker**
 Real-time filtered results

  Visualizations screen :

Map with location pins based on the latitude & longitude information
Bar Chart – Average price by city
Property Type Distribution
Monthly Trends (Listings/Sales)
Table View with full dataset

CRUD Operations screen :

Supports all database tables:

* Listings
* Agents
* Buyers

Each table allows:

Add new records
View records
Update existing records
Delete records

 SQL Queries screen :

Predefined SQL queries in dropdown
Displays:
SQL query
Output results (table)
Helps in understanding data insights

 Tech Stack :

Frontend/UI : Streamlit
Data Processing : Pandas
Database : SQLite3
Visualization : Streamlit Charts + PyDeck (Map)
